# 📝 React To-Do App

🚧 Work in Progress

A simple To-Do application being built with React to practice frontend development concepts.

## 🛠️ Tech Stack

- React.js
- JavaScript
- CSS Modules

## ✨ Planned Features

- Add tasks
- Edit tasks
- Delete tasks
- Set deadlines
- Set task priorities
- Mark tasks as completed

## 🎯 Purpose

This project is being developed to learn React components, state management, forms, and event handling.
